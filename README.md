# Recipe App

スマホで使う簡単なレシピ管理アプリです。純粋な HTML/CSS/JavaScript のみで作られており、サーバーは不要です。データは端末（ブラウザ）の localStorage に保存されます。

## 主な機能

- レシピ一覧（検索：料理名・材料名・手順の単語で検索）
- レシピ詳細表示（材料・手順、メモ、右スワイプでメニューに戻る）
- レシピ作成・編集（画像アップロード、食材選択、分量入力、手順入力）
- 食材（材料）の新規登録（単位を選択：ミリリットル/CC/個/大さじ/小さじ/カップ/合/グラム/その他）

## ローカルで試す

`index.html` をブラウザで直接開いても動作しますが、画像アップロードなどを含め挙動を正しく確認したい場合は簡易サーバーを立てるのがおすすめです。

```
# Python がある場合
python -m http.server 8000
# その後 http://localhost:8000 を開く
```

## GitHub Pages で公開してスマホから使う

1. GitHub上で新しいリポジトリを作成します（Public / Private どちらでも可、Pagesを使うだけならPublic推奨）。
2. このフォルダの内容をそのリポジトリに push します。

   ```
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git branch -M main
   git push -u origin main
   ```

3. GitHub のリポジトリページで `Settings` → `Pages` を開き、
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)`
   を選択して Save します。
4. 数分後、`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできます。
5. スマホのブラウザでこのURLを開き、「ホーム画面に追加」するとアプリのように使えます。

## データについて

- レシピ・食材データはブラウザの localStorage に保存されます。同じ端末・同じブラウザでのみ参照できます（他の端末とは自動で同期されません）。
- ブラウザのキャッシュ削除やアプリ再インストールでデータが消える場合があるのでご注意ください。
