# Recipe Note (デザイン違いバージョン)

`recipe.pdf` の機能要件（メニュー検索、レシピ詳細、レシピ作成フロー、食材登録など）をそのまま実装した、独自デザイン版のレシピ管理アプリです。バックエンド不要の静的HTML/CSS/JSで、データは端末のlocalStorageに保存されます。

デザインはテラコッタ×クリームを基調にした、柔らかい影と丸みのある「レシピノート」風。見出しにセリフ体（Fraunces）、本文にサンセリフ（Inter）を組み合わせています。

## レシピ共有機能

バックエンドを持たない構成のため、サーバー経由の共有ではなく「リンク」または「ファイル」でレシピを送り合う方式です。iPhone(Safari)での利用を想定しています。

- **リンクで共有**（レシピ詳細画面の「共有」ボタン）: レシピ内容（材料名・分量・手順・メモ）をURLに埋め込み、`navigator.share`でiOSの共有シート（メッセージ/AirDrop/メールなど）を開きます。写真はURLが長くなりすぎるため含みません。共有シートに対応していない環境ではリンクをクリップボードにコピーします。
- **ファイルで共有**（写真付きレシピの詳細画面に表示される「📎 画像を含めてファイルで送る」）: 写真を含む`.json`ファイルとして共有シートから送ります。
- **受け取り側**: 共有リンクを開くとそのままインポート確認画面が表示されます。ファイルを受け取った場合はメニュー画面右上の📥ボタンからファイルを選択してください。取り込み時、材料は名前で照合し、未登録の食材があれば自動的に追加します。

## 全データのバックアップ／まとめて共有

1レシピずつではなく、登録した**すべてのレシピと食材**を1つの`.json`ファイルにまとめて書き出す機能です。機種変更前のバックアップにも、レシピ集を丸ごと人に渡す用途にも使えます。

- **書き出し**（メニュー画面右上の📤ボタン）: 全レシピ（写真込み）・全食材を1つのファイルにまとめ、共有シート（保存/送信）を開きます。
- **読み込み**（📥ボタンから同じファイルを選択）: 内容（件数）を確認する画面が表示されます。読み込んでも既存のレシピ・食材は消えず、追加される形です。同じ名前の食材は自動的に統合されます。

## レシピの削除

レシピ詳細画面の一番下にある「レシピを削除」から削除できます。誤って消してしまわないよう、タップしただけでは消えず、確認ダイアログで「削除する」を選んだ場合のみ削除されます（削除すると元に戻せません）。

## アプリのように使う（ホーム画面に追加）

Safariのツールバー無しで、ネイティブアプリのような全画面表示で使えます。

1. iPhoneのSafariでサイトを開く
2. 共有アイコン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ

追加したアイコンから起動すると、アドレスバーやツールバーのない全画面表示になります（PWA対応）。ブラウザで直接開いた場合は通常どおりツールバーが表示されます。

## ローカルで試す

```
python -m http.server 8000
# http://localhost:8000 を開く
```

## GitHub Pagesで公開する

ルートの `recipe-app`（PDF準拠デザイン版）と同じ手順です。このフォルダを別リポジトリにするか、同じリポジトリのサブフォルダとして公開するか（例: `https://<user>.github.io/<repo>/recipe-app-v2/`）お好みで選べます。
